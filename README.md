# ระบบสร้างชุดเบิกพัสดุ (ซื้อ / จ้าง) 6 หน้ามาตรฐาน
ศูนย์การศึกษาพิเศษ ประจำจังหวัดสุโขทัย (ศกศ.สท)

## โครงสร้างโครงการ
- `webapp/` โค้ดระบบหลัก หน้าเว็บ และฐานข้อมูล
- `templates_master/` แม่แบบเอกสาร Word 6 หน้ามาตรฐาน (.docx)
- `app.py` ตัวรันระบบหลัก (รองรับทั้งรันในคอมพิวเตอร์ และรันบน Cloud Render.com)
- `requirements.txt` รายการไลบรารี Python ที่ต้องใช้
- `Procfile` คำสั่งเริ่มทำงานสำหรับเซิร์ฟเวอร์ Render.com
- `start_app.bat` ดับเบิ้ลคลิกรันในคอมพิวเตอร์ Windows

## วิธีรันใช้งานในคอมพิวเตอร์
ดับเบิ้ลคลิกไฟล์ `start_app.bat` หรือเปิด Terminal แล้วพิมพ์:
```bash
python app.py
```
เปิดเบราว์เซอร์ไปที่: http://localhost:5000
